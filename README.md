# Advisor Ice Atlas

An interactive web atlas organizing landfast sea ice U-Net model output and supporting analysis for Arctic coastal communities.

The atlas visualizes landfast ice stability, interannual variability, and bathymetric context across Alaskan and Canadian Arctic communities. It is built as a standalone HTML/JS/CSS site — no server required.

## Contents

- `index.html` — main entry point
- `app.js` — map rendering, pie chart overlays, and interactive sidebar logic
- `styles.css` — layout and styling
- `assets/` — map tile images and community pie chart PNGs
- `data/` — CSV tables (stability metrics, bathymetry, community coordinates)

## Usage

Open `index.html` in a browser. Click any community marker to see ice stability statistics and bathymetric regime breakdown in the sidebar.
